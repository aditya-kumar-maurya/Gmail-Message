# 📧 Gmail Message Sender Using Python

A Python-based Gmail Message Sender application that allows users to send email messages to any recipient programmatically using Python. It uses Gmail SMTP to automate the email-sending process.

## 🚀 Features

- **Send Emails:** Send email messages to any valid recipient email address.
- **Gmail SMTP Integration:** Uses Gmail SMTP server to send emails.
- **Custom Message:** Write personalized email messages.
- **Multiple Recipients:** Send emails to different recipients.
- **Email Automation:** Automate the email-sending process using Python.
- **Secure Authentication:** Supports Gmail App Password authentication.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Email Service:** Gmail
- **Protocol:** SMTP
- **Libraries:** smtplib, email

## 📂 Project Modules

1. Gmail SMTP Connection
2. Sender Email Authentication
3. Recipient Email Input
4. Custom Message Creation
5. Email Sending Functionality

## 🎯 Project Objective

The main objective of this project is to learn email automation using Python and understand how SMTP works to send emails programmatically. It demonstrates how Python can be used to connect with Gmail and send messages to different recipients automatically.
